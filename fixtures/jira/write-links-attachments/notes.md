---
section: "Links and images (write direction) — attachments, titles, labels"
direction: write
---
`[label|^file]` for a labelled attachment link, `[^file]` when the label is the file name, image titles as comma-joined parameters, link titles dropped and formatted labels flattened with warnings, a word-glued link in bracket form, and bare autolinks kept bare (including a URL followed by a full stop and one in parentheses). The image alt reads back as the file name, so the readback differs.
