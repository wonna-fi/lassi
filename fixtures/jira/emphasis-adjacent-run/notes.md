A run of three, and a run of two with a word character on each side. The second is the case that
has no spelling: `_` may not open after a word character nor close before one, so alternating
markers cannot represent `x**a**__b__c`, and writing one marker twice over merges the spans anyway.
Merging is what both cases do. `emphasis-adjacent` covers the plain two-span run.
